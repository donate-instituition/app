A arquitetura inicial do projeto esta documentada em [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Ela define a organizacao de pastas, tema visual, padrao de consumo de API e gerenciamento inicial de estado.

As rotas do Expo Router ficam em `src/app`.
